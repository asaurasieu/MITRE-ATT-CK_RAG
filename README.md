# MITRE-ATTACK_RAG

MITRE ATT&amp;CK RAG chatbot

MITRE provides its data in STIX 2.1 JSON format

STIX stands for Structured Threat Information Expression.

MITRE mantains three main ATT&CK domains:

- Enterprise ATT&CK: attacks targeting enterprise systems, networks, cloud environment, and appications.
- Mobile ATT&CK attacks targeting mobile devices
- ICS ATT&CK attacks targeting industrial control systems

The chatbot should retrieve the technique's description, its associated tactic, and the oficial reference. It should also explain why the technique is relevant rather than simply matching the words.
